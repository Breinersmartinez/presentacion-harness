Especificación: skill auditar-contexto

§1 Resumen

Crear una skill de solo lectura que contraste las fuentes de verdad de AgroCortex con el estado observable del repositorio para detectar contexto obsoleto o contradictorio.

§2 Objetivos

  • Existe en .opencode/skills/auditar-contexto/SKILL.md.
  • Usa una precedencia explícita entre AGENTS, arquitectura, datos y operación.
  • Reporta evidencia, severidad, corrección propuesta y límites.

§3 Fuera de alcance

  • No modifica documentación, código o configuración.
  • No inspecciona artefactos generados o ignorados.
  • No inventa estados de servicios externos o secretos.
  • No realiza una revisión de estilo general.

§4 Diseño

Selecciona el alcance, lee fuentes de verdad, contrasta afirmaciones con evidencia local, clasifica hallazgos y entrega una matriz de coherencia.

§5 Casos borde

  • Si dos fuentes se contradicen, muestra ambas y aplica precedencia sin arreglarlas.
  • Si el estado no es observable localmente, lo marca No verificable.
  • Si un hallazgo solo afecta una fuente histórica, no lo presenta como bloqueante.

§6 Criterios de aceptación

CriterioVerificación
Cada hallazgo cita fuente y evidencia local.Revisar la matriz de coherencia.
Respeta archivos excluidos y ruido de whitespace.Ejecutar y revisar el reporte.
No modifica el repositorio.Revisar el diff tras la auditoría.

§7 Decisiones

Se eligió una auditoría de contexto separada de la validación de producto porque sus evidencias y fuentes son distintas; se descartó corregir automáticamente para que la decisión permanezca en manos del equipo.
