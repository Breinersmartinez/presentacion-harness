Especificación: skill ejecutar-plan

§1 Resumen

Crear una skill que ejecute una única tarea lista del plan, con confirmación previa y evidencia de verificación, sin declarar éxito cuando el criterio no se puede comprobar.

§2 Objetivos

  • Existe en .opencode/skills/ejecutar-plan/SKILL.md.
  • Explica impacto y espera confirmación antes de modificar artefactos.
  • Reporta pasado/no pasado con evidencia, un hallazgo y el tramo al que se debe volver si falla; se detiene tras una tarea.

§3 Fuera de alcance

  • No crea specs ni planes.
  • No continúa automáticamente con la tarea siguiente.
  • No marca tareas terminadas por iniciativa propia.
  • No modifica artefactos fuera del plan.
  • No presupone un lenguaje, framework o proyecto particular: trabaja sobre «artefactos» del plan.

§4 Diseño

Lee spec y plan, selecciona una tarea lista, anuncia el impacto, espera confirmación, ejecuta, verifica y reporta.

§5 Casos borde

  • Si la tarea depende de otra pendiente, no la ejecuta.
  • Si aparece trabajo fuera del plan, se detiene y lo reporta.
  • Si un criterio no es verificable, informa no verificable y no declara éxito.

§6 Criterios de aceptación

CriterioVerificación
No cambia nada sin confirmación.Solicitar una tarea y revisar que pide autorización.
Ejecuta una única tarea.Comparar el plan con los cambios producidos.
Rechaza declarar cumplido un criterio no verificable.Modificar temporalmente un criterio del plan y ejecutar la prueba.
La evidencia cita archivo, comportamiento, salida o valor; nunca usa «listo».Revisar el reporte de una tarea ejecutada.

§7 Decisiones

Se eligió exigir confirmación para proteger artefactos reales; se descartó el modo autónomo porque el ejercicio requiere demostrar control y evidencia antes de seguir.
